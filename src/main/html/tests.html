Bash testing tools

Three packages cover one job: check shell script behavior without a heavy framework.

Roles

PackagePurpose
Bashx.Assertscontextual asserts: on failure prints actual/expected
Bashx.Checksquiet checks: optional message, no detailed diff
Bashx.Mocksbinary stand-ins: curl, rg, cmp, stat, wc

Asserts vs Checks overlap

Both compare strings, ints, and files (eq, ne, contains, exists, execs…).

API difference:

# Asserts — required context
strings/eq.sh "$CONTEXT" "$ACTUAL" "$EXPECTED"


# Checks — message is optional
strings/eq.sh "$ACTUAL" "$EXPECTED"            # quiet
strings/eq.sh "$ACTUAL" "$EXPECTED" "$MESSAGE" # with text
