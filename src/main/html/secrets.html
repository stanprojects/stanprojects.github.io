Cryptography with OpenSSL

Bashx.Hashes and Bashx.Secrets rely on openssl dgst.

Scripts

PackageAction
Hashesbinary SHA-256 digest of a file (-binary, 32 bytes)
Secretssign a file (-sign, algorithm sha256) or verify a signature (-verify)

Shared I/O rules

  • source file: exists, regular file, not a symlink, not empty
  • output file: must not exist yet
  • in Secrets, the key password is passed as an env variable name (env:VAR)
