HTTP clients for external APIs

Bashx.TelegramBots and Bashx.GitHubx are thin wrappers over curl, with response parsing via yq.

What they cover

PackageEndpoints
TelegramBotsgetMe, getUpdates, sendMessage, sendDocument
GitHubx/user, /user/gpg_keys, rate_limit

Shared pattern

  1. strict argument validation (regex, length, types)
  2. response is written to a destination file (dst)
  3. dst must not already exist (and must not be a symlink)
  4. HTTP 200 and non-empty JSON are checked

Telegram call example:

send_message.sh "$BOT_ID" "$BOT_SECRET" "$CHAT_ID" "$MESSAGE" "$DST"

The GitHub token is passed as an environment variable name, not the value:

user.sh GITHUB_TOKEN "$DST"
